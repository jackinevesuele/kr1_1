# Практическая работа № 1 — Proteus, вариант 2

Студент: Босарев Евгений Вадимович, ЭФБО-11-24.

Задача: передать состояние переключателя на светодиод через микроконтроллер. По таблицам 9.3 и 9.4 методички для варианта 2 предусмотрены два аппаратных исполнения:

| Микроконтроллер | Вход | Выход | Порт и регистры |
| --- | --- | --- | --- |
| STM32F103C8 | PA2 | PA3 | GPIOA; RCC->APB2ENR, GPIOA->CRL, IDR, BSRR |
| ATmega32 | PB2 | PB3 | PORTB; DDRB, PINB, PORTB |

Основной пример находится в `stm32/main.c`, альтернативный — в `atmega32/main.c`. Схема подключения и действия в Proteus описаны в `SCHEMATIC.md`.

**Статус:** исходный код и схема подключения подготовлены по методичке. Файл прошивки `.hex`, проект Proteus и подтверждённые скриншоты симуляции появятся после установки подходящих программ и запуска модели. На данном компьютере Proteus и компиляторы для этих микроконтроллеров не обнаружены.
