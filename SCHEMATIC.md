# Подключение схемы в Proteus

## Основной вариант — STM32F103C8

1. Создать проект `PR1_STM32_V2` с коротким путём без кириллицы.
2. Добавить модель `STM32F103C8` (либо совместимую `STM32F100C8`; модель в компиляторе должна совпасть с моделью в Proteus).
3. Добавить `SW-SPDT`, `LED-GREEN`, `RES` 220 Ом, терминалы `POWER` (+3.3 В) и `GROUND`.
4. Общий контакт SW-SPDT соединить с PA2. Один крайний контакт — с +3.3 В, другой — с GND. Это гарантирует явно заданный логический 0 или 1 на входе.
5. PA3 соединить с резистором 220 Ом, затем с анодом светодиода. Катод светодиода соединить с GND.
6. Подключить питание модели по её требованиям. Если конкретная модель требует внешней тактовой цепи, добавить её согласно свойствам модели.
7. Создать проект в CooCox CoIDE для той же модели STM32, подключить CMSIS, CMSIS BOOT, RCC и GPIO, вставить `stm32/main.c`, собрать через Project → Build (F7).
8. В свойствах STM32 в Proteus указать собранный `.hex` в поле **Program File**. Запустить Play.
9. Проверить два положения переключателя: PA2=0 → LED OFF; PA2=1 → LED ON. Сохранить реальные скриншоты обоих состояний.

## Альтернатива — ATmega32

Вместо STM32 использовать ATmega32, переключатель подключить к PB2, светодиод через резистор — к PB3. Питание задавать согласно модели ATmega32 (обычно +5 В). Код находится в `atmega32/main.c`. Проект собрать средой с `avr-gcc`, затем указать полученный `.hex` в Program File модели ATmega32.

## Материалы для отчёта

Нужны вид схемы, исходный код, успешная сборка и путь к `.hex`, поле Program File, состояния 0/LED OFF и 1/LED ON. В отчёте нужно указать вариант 2, модель, выводы, порты и использованные регистры.
